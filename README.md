# CosmicOtterGames Comment Automation — public information

This repository contains only the public information website and privacy policy for an operator-only YouTube creator-comment tool.

- `index.html`: purpose, operator access, contact and policy links.
- `privacy.html`: actual data access, storage, providers, revocation and deletion information.
- `styles.css`: local styling; no scripts, analytics, external fonts, logins or embedded media.
- `.nojekyll`: publish these static files without Jekyll processing.

The automation source, OAuth credentials, runtime secrets, execution logs and posting ledger belong in a separate private repository. Do not add them here.

GitHub Pages initially serves the default repository site. A custom domain can be connected after the site is configured; do not repoint the main CosmicOtterGames website. Keep privacy information aligned with the actual deployment. The documented retention/deletion responsibilities are operator tasks, not claims of automatic cleanup or Google approval.
