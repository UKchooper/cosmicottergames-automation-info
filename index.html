Comment Automation

A private tool for managing our own YouTube channel's creator comments. This website explains the tool and how it handles data.

What the tool does

With the channel owner's permission, the tool uses YouTube API Services to find eligible uploads, check for an existing top-level comment from our channel, and publish a preset creator comment when explicitly enabled. Separate presets can be used for long-form videos, Shorts and particular games.

Comments are written and approved by the operator. The tool does not generate comments using AI. A persistent posting record helps prevent duplicate attempts, and dry-run mode lets the operator inspect a result without posting.

Who can use it

This is an operator-only automation, not a public commenting service. There is no public registration, sign-in or comment-submission form on this site. Running the tool requires access to its private deployment and the authorised channel credentials.

The source code, credentials, execution logs and posting records are kept separately from this public information website.

Privacy and account access

Read our privacy policy for the data accessed, its use and storage, and how to revoke access or request deletion.

Channel owners can revoke Google account access through Google's account permissions settings.
